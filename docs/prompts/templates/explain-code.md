# Template: explain code so I learn it

```text
Explain [file, function or feature] in Signcaster to me. I am a computer science student and I want to understand it well enough to change it myself. Do not edit any files.

1. In two or three sentences, what is it for and where does it fit in docs/ARCHITECTURE.md?
2. Walk through the code in order, in plain language. Point to line numbers.
3. Draw the flow as a short list or a small text diagram (what calls what, which signals fire).
4. Show one small change I could make to practice (for example a new test or a tuning tweak), but do not make it.
5. Ask me one question to check that I understood.
```
